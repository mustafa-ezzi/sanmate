# Premium Sanitary Brand Website Design Guide

## Vision

Create an Apple-inspired premium product showcase for only two
products: - Waste Pipe - Bottle Trap

Focus on storytelling, materials, motion, and lifestyle imagery instead
of a catalog.

## Design Direction

-   Minimal
-   Luxury
-   Lots of whitespace
-   Full-screen sections
-   Smooth scrolling
-   Premium photography

## Color Palette

Background: #F7F7F5 Surface: #FFFFFF Text: #111111 Secondary: #666666
Accent Navy: #0F4C81 Chrome: #C9CED3 Border: #E6E6E6

## Typography

Headings: - Manrope - Inter - Satoshi

Body: - Inter

Hero H1: 72--96px

## CSS Style Guide

Border Radius - 24px - 32px

Shadow 0 20px 60px rgba(0,0,0,.08)

Transitions 0.5--0.8s cubic-bezier(.2,.8,.2,1)

Spacing 120--180px between sections

Buttons Filled: - Navy background - White text

Outline: - Transparent - Navy border

Hover: - Lift 4px - Slight shadow
